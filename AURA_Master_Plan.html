CHAPTER 01 · AI MODEL ENHANCEMENT
AI 예측 모델 고도화 로드맵
현행 다변량 선형회귀의 구조적 한계를 진단하고, 비선형 특성을 반영한 단계별 모델 전환 계획을 제시합니다.
현행 모델의 진단 AS-IS

현행 v5.2는 다변량 선형회귀(Multiple Linear Regression) 모델을 채택하고 있습니다. 구역별 개별 모델 + 시간대 가중치(11~14시 1.5배) 적용으로 운영 안정성은 확보하였으나, 다음과 같은 본질적 한계가 존재합니다.

한계 항목상세 내용실측 영향
비선형성 미포착 포장온도는 일사량과 비선형 관계(흑체 복사식 4제곱 비례)이나, 선형회귀는 1차식만 학습 고온구간(55℃↑) 예측오차 ±2~3℃
변수 상호작용 무시 풍속·일사량의 교호작용(바람이 강하면 일사 효과 감쇠) 미반영 강풍일 과예측 경향
시계열 의존성 부재 직전 1시간 온도 추세가 입력되지 않아 급변 상황 대응 지연 경보 발령 5~10분 지연
데이터 부족 샘플 데이터 기반 학습 — 계절·날씨 다양성 부족 겨울철·우천 시 신뢰도↓

P1 핵심기능 상세 — 살수 이력 관리 DB F-01 DETAIL

현행은 운영로그가 브라우저 메모리에만 존재하며 새로고침 시 소실됩니다. 운영 기록의 영속화는 향후 책임소재 추적·민원 대응의 필수 자료가 되므로 최우선 기능으로 분류합니다.

권장 기술 스택 TECH STACK

현행 유지 (저비용 운영을 위해 백엔드 도입은 신규기능 단계에서):

  • 프론트엔드: Vanilla JS (ESM 모듈) — 프레임워크 없이 경량성 유지
  • 차트: Chart.js (현행 유지)
  • 엑셀 처리: SheetJS (현행 유지)
  • 테스트: Vitest (경량 + 빠름)
  • 번들러: Vite (선택 — 빠른 dev server)

F-01·F-02·F-03 도입 시점에 추가:

  • 백엔드: Node.js + Express (또는 NestJS)
  • DB: PostgreSQL (시계열 데이터 강점) 또는 SQLite (소규모)
  • 인증: JWT + bcrypt
  • 알림: NHN Cloud SMS / 카카오 비즈니스
